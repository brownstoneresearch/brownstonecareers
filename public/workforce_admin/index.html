SYSTEM READINESS

Production controls and service health.

Review the backend capabilities available to this deployment. Candidate administration requires D1; sensitive uploads require D1, R2, and the PII encryption secret.

Recommended production protections

  • Protect workforce.brownstonecareers.agency with Cloudflare Access and MFA.
  • Restrict administrators by approved email and least-privilege roles.
  • Rotate session, invitation, and PII encryption secrets.
  • Keep the R2 bucket private and review document retention schedules.
  • Use the D1 audit trail for every material administrator action.
  • Keep each Resend workflow key in encrypted Cloudflare secrets; never store keys in the website source.
