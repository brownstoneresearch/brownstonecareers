# Brownstone Careers Workforce Platform v10.0

## Autonomous operations
- New Autopilot control center in the administrator dashboard.
- Governed rule engine for invitation reminders, stalled-journey alerts, pre-screening review alerts, stage confirmations, and ranking refreshes.
- Durable automation queue with retry state, failure visibility, deduplication, and operations-health snapshots.
- Optional Cloudflare scheduled Worker runs every 15 minutes, so automation continues when no administrator has the dashboard open.

## Mature experience
- Upgraded public homepage with an accountable four-step operating-system narrative.
- Real-time Autopilot health, rule toggles, run history, queue counts, and manual run control.
- Existing candidate IDs, personal access codes, invitation status/stage templates, private R2 documents, D1 records, stage notifications, rankings, and human-reviewed AI grading remain intact.

## Governance
Automation may remind, route, notify, rank verified completion, and prepare review work. Final hiring, rejection, identity approval, and released assessment decisions remain authorized administrator actions.
